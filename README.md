# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — файл JavaScript;
- `images/` — папка для изображений;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Самостоятельные доработки (КР №1, п. 14 практики №8)

По методическим указаниям к практическому занятию №8 для оценки выше базового уровня проект нужно дополнить самостоятельными улучшениями. Из предложенного списка реализованы семь пунктов.

### 1. Sticky-фильтр каталога
Панель фильтров на странице `catalog.html` остаётся на экране при прокрутке списка товаров (`position: sticky`). Высота шапки записывается в CSS-переменную `--header-height`, поэтому фильтр не заезжает под неё. Фильтры работают: по категории, цене и наличию, с кнопкой «Сбросить» и счётчиком найденных товаров.

### 2. Варианты карточек через БЭМ-модификаторы
Блок `product-card` получил модификаторы: `--featured`, `--new`, `--discount`, `--compact`, `--out-of-stock`, `--selected`. Добавлены элементы `product-card__badge`, `product-card__price-old` и `product-card__actions`.

### 3. Дополнительные состояния кнопок и карточек
- кнопки: `:active`, `:disabled`, `aria-pressed`, модификаторы `--small`, `--ghost`, `--icon`;
- карточки: `:hover`, `:focus-within`, «нет в наличии», «в избранном»;
- анимации отключаются при `prefers-reduced-motion`.

### 4. Улучшенная доступность формы
- обязательные поля отмечены звёздочкой;
- сообщение об ошибке показывается под каждым полем и связано с ним через `aria-describedby` и `aria-invalid`;
- сводка ошибок с `role="alert"`, фокус переходит на первое ошибочное поле;
- проверка при уходе с поля и исправление ошибки по мере ввода;
- атрибуты `autocomplete`, подсказка формата телефона;
- из CSS удалено правило, блокировавшее остальные поля при фокусе на одном.

### 5. Блок отзывов
Секция `#reviews` на главной: средняя оценка и три карточки отзывов (`review-card`). Оценка читается скринридером текстом («Оценка: 5 из 5»), даты размечены тегом `<time>`.

### 6. Блок часто задаваемых вопросов
Секция `#faq` на главной сделана на `<details>` и `<summary>` без JavaScript. Одновременно раскрыт один вопрос.

### 7. Улучшенное модальное окно
- кнопка закрытия «✕» и название выбранного товара в заголовке;
- закрытие по `Esc`, по клику на затемнённый фон и по кнопкам;
- блокировка прокрутки страницы, пока окно открыто;
- возврат фокуса на кнопку, открывшую окно;
- после отправки фокус переходит на сообщение об успехе;
- плавное появление окна.
